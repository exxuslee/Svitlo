# Международные источники отключений

Проверено 15 ноября 2026 года. С 16 ноября страна выбирается первым шагом
добавления карточки и сохраняется в её параметрах. На главном экране могут
одновременно находиться карточки разных стран. В настройках выбора страны нет.
Украина использует существующие графики, виджеты и уведомления. Международный
экран объединяет события одного адреса в карточку с тем же компонентом,
что используется для Украины: переключатель «Сегодня / Завтра», интервалы и
почасовая шкала из 48 получасовых ячеек. Сохраняются исходные адреса, поиск и
местное время. Точные даты событий, включая более поздние дни, приведены под
шкалой. Международные события пока не подключены к виджетам и уведомлениям.
Область обслуживания оператора не равна всей стране.

`InternationalScheduleMapper` — общий адаптер для всех стран и операторов.
Он обрезает интервалы по местным суткам и объединяет пересечения. Полностью
покрытая ячейка обозначает отключение; частично покрытая ячейка — жёлтая.
При переводе часов повторённая ячейка красная только тогда, когда обе её
реальные получасовые части покрыты отключением. Несуществующие часы и часы
без подтверждённых данных остаются неизвестными. Отсутствие события не
преобразуется в наличие электричества. Для источников без API выводится
карточка с неизвестными ячейками и отдельным статусом доступности источника.

## Подключённые API

| Страна | Оператор | Реализация и проверка |
| --- | --- | --- |
| Великобритания | UK Power Networks | OpenDataSoft Explore v2.1, `ukpn-live-faults/records`, постраничная загрузка. Проверен HTTP 200 с живыми событиями. Восстановленные события исключаются. Поиск по районам и почтовым индексам. CC BY 4.0, атрибуция и ссылка на источник отображаются в интерфейсе. |
| Канада | Manitoba Hydro | ArcGIS `Manitoba_Hydro_Planned_Power_Outages/FeatureServer/0/query`. Проверен HTTP 200 с запланированными отключениями, адресами и датами в миллисекундах Unix. Ошибки и неполная выборка не считаются пустым графиком. |
| Польша | Tauron Dystrybucja | `/waapi/enum/geo/cities`, `/waapi/enum/geo/streets`, `/waapi/outages/address`. Проверены поиск Kraków, улица Dietla и ответ с событиями. Выбор города и улицы использует GAID, а не неоднозначное название. Ответ с `OutageListType=2` отмечается как событие в районе. |

Основные страницы данных:

## Остальные источники из исходного списка

Они включены в каталог страны со ссылкой и явным статусом. Ссылка на сайт не
означает реализованную загрузку графика в приложении.

| Источник | Результат проверки / что остаётся сделать |
| --- | --- |
| NGED | Документация публикует CKAN и CSV. При прямой проверке оба адреса вернули HTTP 403. В приложении доступна официальная карта. Нужна проверка разрешённого доступа и формата ответа перед подключением адаптера. |
| Hydro-Québec | Документированный `aipversion.json` вернул HTML страницы недоступности вместо JSON. CC BY-NC 4.0. Нужен доступ из поддерживаемого региона и проверка актуальных AIP/BIS payload; парсер по старому примеру не включён. |
| Eskom Calendar | README сообщает об архивации. Исторические данные заканчиваются в мае 2025 года. Не используется как источник текущих графиков. Данные CC BY-NC-SA 4.0. |
| ESP | Для показа данных пользователям требуется письменное коммерческое разрешение. Пользователь подтвердил отсутствие ключа/разрешения. Запросы не выполняются, ключ в APK не добавляется. |
| Cape Town | Endpoint отвечает HTTP 200, но метаданные `lastUpdated` — 2025-05-13. Это стадии load shedding, а не адресные интервалы; нужны актуальность и районные таблицы. |
| Enea | Библиотека использует HTML-страницы и формы, это не JSON API. Прямая проверка страницы завершилась тайм-аутом. Надёжный парсер и контроль изменения разметки ещё не реализованы. |
| PGE | Указанный Node-RED flow парсит HTML-таблицу. Поддержка сайта есть через ссылку; парсер таблицы не реализован. |
| Pakistan DISCO / PITC, K-Electric | Открываются официальные сайты. Из исходного списка нет проверенного публичного JSON API. Для индивидуальных графиков нужны отдельные интеграции операторов. |
| Ecuador / CNEL | Открывается официальный сайт CNEL. Новость 2024 года не является текущим API графиков. |
| Ireland / ESB | Старый `/rota` вернул HTTP 404. Ссылка заменена действующим PowerCheck; загрузка данных карты пока не реализована. |
| Kenya Power | Открывается сайт оператора с поддержкой и объявлениями; API графиков не подтверждён. |
| Mexico / CFE | Открывается официальный сайт CFE; API графиков не подтверждён. |

## Проверки

Модульные тесты проверяют постраничную загрузку, исключение завершённых
отключений, миллисекунды Unix, временные зоны, область действия Tauron,
ошибки HTML/ArcGIS и изоляцию каталогов стран. Ошибка сети, неполный ответ или
отсутствие совпадений не отображаются как подтверждение наличия электричества.
