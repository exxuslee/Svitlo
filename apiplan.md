# План реализации интеграции новых API графиков отключений

## Состояние реализации — 16 ноября 2026

Подключены проверенные публичные источники. Часть исходных предположений ниже не подтвердилась; незакрытые пункты остаются незакрытыми. Добавление оператора в каталог со ссылкой на его сайт не означает готовую API-интеграцию.

### Реализовано

- YASNO и существующие GitHub JSON: условные запросы `ETag` / `If-None-Match` и `Last-Modified` / `If-Modified-Since`, корректный повторный разбор тела при `304`. В кеш попадают только проверенные ответы. Ошибки сети и изменения схемы диагностируются через `FeedFailureReporter` (`OutageFeed` в Android).
- UA Power Outages Monitor: отдельный тип источника `ukraine_monitor`, разбор `artifacts/last-message.json`, выбор региона через `cpu`, группы → дата → получасовые слоты. Добавлены 16 вариантов источника в украинский каталог, включая новые Черкасскую и Харьковскую области. Старые поставщики и сохранённые адреса сохранены. Пропуски, устаревшие дни и аварийный режим дают неизвестные слоты, а не подтверждение наличия света.
- Opendatasoft: общий клиент Explore v2.1 с `select`, `where`, `order_by`, пагинацией и необязательным ключом в заголовке. На него переведён UKPN и подключён Northern Powergrid (`live-power-cuts-data`, `isaffected=1`).
- CKAN: общий клиент `datastore_search` с `filters`, `sort`, `offset`, пагинацией и проверкой `success`; `package_show` для поиска актуальных ресурсов. Конкретные ресурсы NGED/ANEEL пока не подключены.
- SSEN: `getallfaults` и `getbyid/{reference}`. `loggedAtUtc` планового задания не используется как время начала отключения. Просроченная оценка восстановления сама по себе не означает устранённую аварию.
- ODIN: публичный `GET /odi/map?scale=COUNTY`, необязательный фильтр `countyCd`. Сводки по округам отображаются без вымышленных временных интервалов.
- eskom-calendar: готов CSV-адаптер с исходной колонкой `finsh`, часовыми поясами и экранированными полями. Проект архивирован, поэтому автоматическая загрузка в приложении не включена и статус `ARCHIVED` сохранён.
- Добавлены страны и операторы из плана; для неподтверждённых API используется ссылка на официальный сайт либо существующие статусы недоступности/необходимости разрешения.

Проверено: `:domain:test`, `:data:testDebugUnitTest`, `:app:testDebugUnitTest` — 134 теста без ошибок; `:app:assembleDebug` и `:app:lintDebug` завершаются успешно. Новые сетевые интеграции дополнительно проверены реальными GET-запросами. Приёмочные тесты покрывают `304`, повреждённые ответы, отмену, независимые запросы регионов, пагинацию, аварийные/устаревшие украинские графики и отсутствие вымышленных интервалов у сводок/плановых заданий.

## 1. Европа (Open Data и национальные операторы)

- [ ] **Франция — Enedis Open Data**
  - **Базовый URL / Эндпоинт:** `https://data.enedis.fr/api/explore/v2.1/catalog/datasets/{dataset_id}/records` (актуальный `dataset_id` ищется через `/catalog/datasets?where=search(title, "coupures")`).
  - **Авторизация:** Не требуется (публичный доступ, лимит на частоту запросов без ключа).
  - **Как пользоваться:** Отправлять `GET`-запросы с параметром `where` для фильтрации по региону или индексу (например, `?where=code_postal="75001"&limit=50`). Ответ приходит в стандартном JSON с координатами, статусом и временем начала/окончания работ.

- [ ] **Ирландия — ESB Networks PowerCheck API** ⚠️
  - **Базовый URL / Эндпоинт:** `https://powercheck.esbnetworks.ie/api/outages` (внутренний REST-фид карты отключений).
  - **Авторизация:** Не требуется (требуется стандартный заголовок `User-Agent` и `Referer: https://powercheck.esbnetworks.ie/`).
  - **Как пользоваться:** Делать `GET`-запрос раз в 10–15 минут. Эндпоинт возвращает массив объектов с типом (`Fault` или `Planned`), координатами (`lat`/`lng`), количеством затронутых клиентов и полем `estimatedRestoreTime`.

- [ ] **Скандинавия — Fingrid Open Data (Финляндия)**
  - **Базовый URL / Эндпоинт:** `https://data.fingrid.fi/api/datasets/{datasetId}/data` (например, наборы по плановым ограничениям передачи и генерации).
  - **Авторизация:** Бесплатный API-ключ (получается после регистрации на `data.fingrid.fi`), передается в заголовке `x-api-key: YOUR_KEY`.
  - **Как пользоваться:** Указывать временной диапазон в параметрах `startTime` и `endTime` в формате ISO 8601 (`2026-11-16T00:00:00Z`).

- [ ] **Польша — Tauron / Energa (JSON-фиды плановых отключений)** ⚠️
  - **Базовый URL / Эндпоинт:**
    - Tauron: `https://www.tauron-dystrybucja.pl/iapi/outage/GetOutages`
    - Energa: `https://energa-operator.pl/iapi/outage/GetOutages`
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Передавать в `GET`-параметрах ID региона/города (`divisionId`, `districtId`) или координаты bounding box карты (`latMin`, `latMax`, `lonMin`, `lonMax`). В ответе приходят массивы с точными адресами (улицы, номера домов) и временными интервалами (`StartDate`, `EndDate`).

## 2. Великобритания

- [x] **SSEN Power Track (север Шотландии и центральный юг Англии)**
  - **Базовый URL / Эндпоинт:** `https://external.distribution.prd.ssen.co.uk/opendataportal-prd/v4/api` с путями `/getallfaults` и `/getbyid/{reference}`.
  - **Авторизация:** Заявлен анонимный доступ. В описании источника отмечено, что анонимные вызовы документированных эндпоинтов могут возвращать 404, поэтому сначала проверить `curl`-ом.
  - **Как пользоваться:** `GET /getallfaults` возвращает плановые и внеплановые отключения: номер аварии, тип, координаты, ожидаемое время восстановления, затронутые почтовые индексы. Детали по одной аварии: `GET /getbyid/{reference}`.
  - **Дополнительно:** портал данных SSEN Distribution (`https://data.ssen.co.uk/`) работает на CKAN Action API.

- [x] **UK Power Networks (Лондон, восток и юго-восток Англии)**
  - **Базовый URL / Эндпоинт:** `https://ukpowernetworks.opendatasoft.com/api/explore/v2.1/catalog/datasets/{dataset_id}/records` (набор live faults — near real time фид из системы PowerOn).
  - **Авторизация:** Для части данных может потребоваться логин на портале.
  - **Как пользоваться:** Стандартный Opendatasoft Explore API v2.1 (см. п. 7). Включает плановые и внеплановые отключения.

- [ ] **National Grid Electricity Distribution (Мидлендс, юго-запад Англии, Уэльс)**
  - **Базовый URL / Эндпоинт:** `https://connecteddata.nationalgrid.co.uk/dataset/live-power-cuts` (портал на CKAN, есть CSV «Live Power Cuts» и «Live Detailed Power Cuts»).
  - **Авторизация:** Не требуется для открытых ресурсов.
  - **Как пользоваться:** Скачивать CSV-ресурсы по прямой ссылке (обновление почти в реальном времени, примерно раз в час) или использовать CKAN `datastore_search`, если ресурс загружен в datastore.

- [x] **Northern Powergrid (северо-восток Англии, Йоркшир)**
  - **Базовый URL / Эндпоинт:** Opendatasoft Explore API v2.1 на портале Northern Powergrid.
  - **Авторизация:** Часть данных открыта, для полного доступа нужна регистрация.
  - **Как пользоваться:** Только `GET`, JSON, язык запросов ODSQL (см. п. 7).

## 3. Украина

- [x] **YASNO (Киев, Днепр)**
  - **Базовый URL / Эндпоинт:** `https://app.yasno.ua/api/blackout-service/public/shutdowns/regions/{regionId}/dsos/{dsoId}/planned-outages`
  - **Идентификаторы:** Киев: `regions/25/dsos/902`. Днепр (DNEM): `regions/3/dsos/301`. Днепр (CEK): `regions/3/dsos/303`.
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** `GET` возвращает JSON со слотами отключений. Тип слота: `Definite` (подтверждённое) или `Possible` (возможное). Слоты описывают периоды отсутствия света; если слотов на интервал нет, свет есть. Аварийный режим приходит в поле статуса (`EmergencyShutdowns`). Поддерживать условные запросы (`304 Not Modified`).

- [ ] **DTEK (региональные сайты)** ⚠️
  - **Базовый URL / Эндпоинт:** WordPress AJAX на сайтах областных компаний DTEK (`/ua/ajax`).
  - **Авторизация:** Официального API нет. Нужны cookies и CSRF-токен со страницы графика.
  - **Как пользоваться:** Двухшаговый запрос: сначала `GET` страницы графика для получения cookies и токена, затем `POST` на AJAX-адрес с городом, улицей и номером дома. Как референс можно использовать Python-библиотеку `dtek-blackout-client` (PyPI). Интеграция хрупкая, ломается при изменении сайта.

- [x] **Обленерго через GitHub JSON и готовый агрегатор**
  - **Базовый URL / Эндпоинт:** репозиторий `chaichuk/UA-power-outages-monitor` (агрегатор 18+ регионов), файлы `artifacts/*.json` через `https://raw.githubusercontent.com/chaichuk/UA-power-outages-monitor/main/artifacts/{region}.json`. Агрегированный файл: `last-message.json`.
  - **Авторизация:** Не требуется.
  - **Формат:** три уровня: группа → дата (`YYYY-MM-DD`) → получасовой слот (`HH:00` / `HH:30`), значение `1` = свет есть, `2` = света нет. В агрегатор подключены 12 областей через GitHub JSON (Львов, Полтава, Черкассы, Чернигов, Харьков, Хмельницкий, Ивано-Франковск, Ровно, Тернополь, Закарпатье, Запорожье, Житомир), а также Киев и Днепр через YASNO.
  - **Как пользоваться:** Опрашивать с `ETag` / `If-None-Match` (см. п. 8).

## 4. Северная Америка

- [x] **ODIN — Outage Data Initiative Nationwide (США, ORNL)**
  - **Базовый URL / Эндпоинт:** `https://odin.ornl.gov/` (Swagger: `https://odin.ornl.gov/swagger-ui/index.html`, статус: `https://odin.ornl.gov/odi/status`).
  - **Авторизация:** Публичный анонимный API без ключа. Расширенный API с более детальными данными требует авторизации.
  - **Как пользоваться:** Анонимный API отдаёт текущие отключения на уровне округов (FIPS-код). Один источник на всю страну вместо сотен сайтов энергокомпаний.

- [ ] **Hydro-Québec (Канада, Квебек)**
  - **Базовый URL / Эндпоинт:** Открытые данные через портал Données Québec (точный URL ресурса брать на странице набора данных на `hydroquebec.com/documents-data/open-data/`).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Набор «Pannes en cours» (текущие отключения) в режиме API: местоположение, число клиентов без света, время начала, причина (если известна), ожидаемое время восстановления. Отдельный набор по плановым прерываниям.

## 5. Австралия и Новая Зеландия

- [ ] **Австралия — Ausgrid / Energex Outage Feeds** ⚠️
  - **Базовый URL / Эндпоинт:**
    - Ausgrid: `https://www.ausgrid.com.au/webapi/OutageMap/GetOutages`
    - Energex: `https://www.energex.com.au/static/Energex/Outages/outages.json` (или ArcGIS REST-сервисы дистрибьюторов).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Прямой `GET`-запрос отдает GeoJSON или JSON со списком текущих и запланированных отключений (`Planned` / `Unplanned`), полигонами зон (`geometry`), причиной (`cause`) и статусом ремонтной бригады.

- [ ] **Австралия — Western Power (Западная Австралия)** ⚠️
  - **Базовый URL / Эндпоинт:** `https://www.westernpower.com.au/api/corp/outage/*` (недокументированный JSON API, питающий публичный трекер отключений).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** `GET` возвращает все текущие и предстоящие отключения, есть методы для деталей и статуса отдельной аварии, а также поиска. Дополнительно: ArcGIS Feature Service с зонами отключений и сетевые данные через `services.slip.wa.gov.au`.

- [ ] **Новая Зеландия — Vector / Powerco Outage API** ⚠️
  - **Базовый URL / Эндпоинт:**
    - Vector: `https://www.vector.co.nz/api/outages`
    - Powerco: `https://www.powerco.co.nz/api/outages`
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Выполнять `GET`-запрос; ответ содержит список районов (`suburb`), статус работ, тип отключения (плановое/аварийное) и время предполагаемого включения.

## 6. Азия, Индия, Африка

- [ ] **Индия — National Power Portal (NPP) & Urja Mitra** ⚠️
  - **Базовый URL / Эндпоинт:** Внутренние XHR/JSON-эндпоинты порталов штатов (например, BESCOM для Карнатаки или MSEDCL для Махараштры) и сводки `urjamitra.com`.
  - **Авторизация:** Не требуется, но порталы часто используют ASP.NET ViewState или CSRF-токены сессии.
  - **Как пользоваться:** Реализовать двухшаговый запрос: сначала `GET` главной страницы для получения cookies/токена, затем `POST`-запрос к эндпоинту выборки по коду штата (`stateCode`) и фидера (`feederId`), либо подключить готовые Python-скрейперы с GitHub.

- [ ] **Филиппины — Meralco & NGCP** ⚠️
  - **Базовый URL / Эндпоинт:** Секция уведомлений Meralco (`company.meralco.com.ph/news-and-advisories` — отдается через внутренний JSON-поиск Drupal/CMS) и RSS/веб-таблицы NGCP (`ngcp.ph`).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Настроить регулярный парсинг RSS-ленты или JSON-ответа фильтра новостей по тегу `Maintenance Schedule` с извлечением даты, города (`City/Municipality`) и временного слота регулярными выражениями.

- [ ] **Южная Африка — eskom-calendar (открытый проект)**
  - **Базовый URL / Эндпоинт:** репозиторий `https://github.com/beyarkay/eskom-calendar`, CSV: `https://github.com/beyarkay/eskom-calendar/releases/download/latest/machine_friendly.csv`. Также есть бесплатный открытый API проекта (версия 0.0.1, возможны шероховатости).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Скачивать CSV (колонки с временем начала и конца отключений по зонам и ступеням) или использовать API проекта. Периодически перечитывать файл с проверкой `ETag`.

  - **Базовый URL / Эндпоинт:** `https://www.sec.cl/sitio-web/wp-content/uploads/clientes_sin_suministro/` (публичные JSON/CSV-данные о клиентах без электричества по коммунам и компаниям).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Опрашивать агрегированный JSON-файл с разбивкой по регионам (`region`), коммунам (`comuna`) и дистрибьюторам (`empresa`), где указано количество затронутых абонентов.

- [ ] **Бразилия — ANEEL Open Data**
  - **Базовый URL / Эндпоинт:** `https://dadosabertos.aneel.gov.br/api/3/action/datastore_search?resource_id={resource_id}` (стандартный CKAN API).
  - **Авторизация:** Не требуется.
  - **Как пользоваться:** Использовать параметры CKAN API (`filters={"SigAgente":"ENEL SP"}`, `limit=100`, `sort=_id desc`) для получения записей о плановых и аварийных перебоях в работе распределительных сетей.

- [ ] **Израиль — IEC (Israel Electric Corporation)** ⚠️
  - **Базовый URL / Эндпоинт:** `https://www.iec.co.il/api/outages` (внутренний REST-сервис портала проверки отключений).
  - **Авторизация:** Не требуется (нужны стандартные заголовки браузера `Accept: application/json`).
  - **Как пользоваться:** Отправлять `GET` или `POST` с идентификатором населенного пункта (`cityId`) и улицы (`streetId`), получая список запланированных работ (`PlannedWorks`) и текущих аварий с временем окончания.

## 8. Универсальные адаптеры и комьюнити-агрегаторы

- [x] **Единый коннектор для Opendatasoft (Франция, Бельгия, Швейцария, Великобритания, США)**
  - **Базовый URL / Эндпоинт:** `https://{operator_domain}/api/explore/v2.1/catalog/datasets/{dataset_id}/records`
  - **Авторизация:** Опционально (для большинства публичных датасетов ключ не нужен; для повышенных лимитов передается `?apikey=YOUR_KEY`).
  - **Как пользоваться:** Написать один базовый класс клиента, принимающий домен и `dataset_id`. Использовать единый язык запросов ODSQL в параметрах `select`, `where` (фильтрация по дате и геопозиции `within_distance(geo_point, geom'POINT(lon lat)', 5km)`) и `limit`. Подходит для Enedis, UK Power Networks, Northern Powergrid, SSEN Transmission.

- [x] **Единый коннектор для CKAN (Бразилия, Великобритания и др.)**
  - **Базовый URL / Эндпоинт:** `https://{portal_domain}/api/3/action/datastore_search?resource_id={resource_id}`
  - **Авторизация:** Для открытых ресурсов не требуется.
  - **Как пользоваться:** Один клиент с параметрами `filters`, `limit`, `sort`, `offset`. Подходит для ANEEL, National Grid ED, SSEN Distribution (портал данных).

- [ ] **Мониторинг GitHub-репозиториев (Молдова, Грузия, Ливан, Пакистан, Украина и др.)**
  - **Базовый URL / Эндпоинт:** `https://raw.githubusercontent.com/{owner}/{repo}/main/{path_to_schedule}.json`
  - **Авторизация:** Не требуется (для публичных репозиториев).
  - **Как пользоваться:** Найти актуальные репозитории по тегам `power-outage` / `load-shedding`, которые обновляют файлы через GitHub Actions по cron. Подключить прямой `GET` к `raw.githubusercontent.com` с проверкой заголовка `ETag` или `If-None-Match`, чтобы не скачивать файл повторно, если график не менялся.
